Headline

Accuracy counts only fields the document actually states. Correct abstentions are excluded from it deliberately — they are measured by abstention precision, the one metric that punishes answering when the honest move was to decline.

Failure taxonomy

Every labelled field lands in exactly one bucket, so the counts partition the run. A numerically right answer whose citation failed verification is ungrounded, not correct — an unverifiable number cannot go in a credit memo.

Derived ratios

Leverage and DSCR are computed twice by the same plain-Python code — once from the extraction, once from ground truth — so a disagreement is always a sourcing error and never arithmetic. Abstention is a result here: a DSCR the document cannot support should come back refused, with the input that killed it named.

Abstention & calibration

The curve is the whole accuracy/abstention frontier. The marked point is the split-conformal operating point — a threshold derived from a held-out calibration split rather than hand-picked, so it carries a finite-sample guarantee instead of a hunch.

Per line item

The extractor is only ever asked for line items, never for a ratio. This table is where a systematic sourcing failure shows up as a single bad row.
