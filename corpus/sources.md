# Sources

Provenance for every document in this corpus. `pdfs/` is git-ignored, so this
file is what lets someone else reassemble the same corpus and check the labels
against the same documents.

**No hand-labelled documents yet.** See `README.md` for where to get them.

An imported corpus is available as a stopgap and is recorded below. It is
generated by `anchor import` into a git-ignored directory, because the source
dataset declares no licence.

| Corpus | Source | Licence | Documents | Fields annotated |
|---|---|---|---|---|
| `corpus/kleister-charity` | [Kleister Charity](https://github.com/applicaai/kleister-charity), Charity Commission for England and Wales | none declared | 2,788 available; 15 imported | `revenue_ltm` only |

[LEDGER](https://arxiv.org/abs/2606.13100) is the better licensed option and has
no adapter yet: CC-BY-4.0 data, 4,999 OCR'd annual reports, 31 KPIs including
revenue, cash and equivalents, interest expense, and long- and short-term debt,
with page-level relevance judgements that would map onto Anchor's `page` field.
Its authors excluded EBITDA on the grounds that it is reporting-standard
dependent and derivable from components, which is the same judgement this
harness makes.

## Format

One row per document. `doc_id` must match the filenames in `pdfs/` and
`golden/`.

| doc_id | Entity | Register | URL | Retrieved | Period | Pages | Scanned |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Fill in:

- **Register**: ACNC, UK Charity Commission, Companies House, or the specific
  government site. Name it precisely enough that someone can search it.
- **URL**: the page you downloaded from, not a search result.
  Registers reissue document links, so record the record page too if the direct
  link is a signed URL.
- **Retrieved**: the date you downloaded it. Registers replace filings, and a
  label written against the 2023 version is wrong for the 2024 one.
- **Period**: the financial year the statements cover, so a reader can tell
  which column the labels refer to.
- **Scanned**: whether the text layer came from OCR. This drives the `scanned`
  flag on the `GoldenRecord` and explains grounding failures that are the
  document's fault rather than the extractor's.

## Licensing

Check each register's terms before redistributing anything. Most allow download
and use but not republication, which is why `pdfs/` is git-ignored. Recording a
URL here is not redistribution; committing the PDF would be.
